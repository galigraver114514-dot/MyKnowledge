# Unit 02 · 分数速览

> 目标：理解分子/分母，会做同分母加减。

## 1. 结构与含义
- `a/b`：把整体分成 `b` 份，取 `a` 份。
- 分子（a）在上，分母（b）在下；分母 ≠ 0。

例：`3/4` 表示 4 份取 3 份。

## 2. 同分母加减
分母不变，分子相加减。

- `1/5 + 2/5 = 3/5`
- `4/7 - 1/7 = 3/7`
- 得数能约分要约分：`2/4 = 1/2`
