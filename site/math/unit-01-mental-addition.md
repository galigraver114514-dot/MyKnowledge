# Unit 01 · 心算加法

> 目标：两位数加法不列竖式，5 秒内出结果。

## 方法一：拆十补整
把较小数拆开，让较大数凑整再算。

- 例：47 + 26 → 47 + 3 = 50，剩 23 → 50 + 23 = **73**
- 例：38 + 45 → 38 + 2 = 40，剩 43 → 40 + 43 = **83**

## 方法二：先十位后个位
从高位算，逐步加，不易遗忘。

- 例：64 + 29 → 64 + 20 = 84 → 84 + 9 = **93**
- 例：58 + 37 → 58 + 30 = 88 → 88 + 7 = **95**
