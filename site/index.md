# 学习地图

> **MyKnowledge** —— 私人学习网站。内容公开在 GitHub Pages；**你的行为数据只存在本机浏览器**（IndexedDB，实时落盘），
> 可一键导出/导入/快照复原。架构与语义见仓库 `specs/data-model.md`。

## 使用流程（每单元）

1. 打开一个单元页面（自动记录一次 `unit_open`）
2. 按页面内容学习 → 完成页底自检
3. 学完点页面下方"标记完成"（记录 `unit_complete`，可随时撤销）
4. 定期**导出**一份 JSON 留作离线复原副本；误操作时用快照/导入回滚

## 复原手册（三句话）

- **日常**：浏览器内快照自动留最近 5 份 → 误操作可从快照恢复
- **换机/换浏览器**：旧机导出 → 新机导入
- **灾难恢复**：清空 → 导入最近导出文件 → 状态逐字段一致（幂等，可重复执行）
